## Faithfulness check

All three refs are genuine independent strict-fidelity attempts, not copies of one
shortcut: each independently (a) collapsed the multi-asset problem to a scalar AAPL
weight, (b) estimated r and Σ from a trailing 252-bar return window, (c) maximized the
spec's objective by 1-D grid search (no solver importable), and (d) realized w* via
`order_target_percent` — a justified deviation from the D4a plain-buy/sell default
because the spec is explicitly weight-based ("Find the optimal asset weights `w*`",
"open new ones in accordance with the new target weights `w*`"). All three declared
extensive ASSUMPTIONS lists naming the same unpinned choices.

## Where the tapes diverge, and the spec phrase each divergence traces to

1. **Numeric values of λ and Θ — never given.** The spec defines them only as
   "`λ` — risk coefficient (risk aversion) that determines the importance of risk
   compared to return" and "`Θ` — coefficient that scales market impact costs", and
   even instructs "Use this parameter to control between aggressive (high return, high
   risk) and conservative (low return, low risk) trading" — i.e., an explicitly free
   knob. ref0 chose λ=2.0, Θ=0.01; ref1 λ=1.0, Θ=0.01; ref2 λ=1.0, Θ=0.1. ref2's 10×
   impact coefficient directly explains its 74-fill tape (trading suppressed) vs 543
   and 254; λ scales the optimal w* and hence every rebalance size/direction.
   → `unpinned-indicator-params`.

2. **The objective's last term is internally contradictory.** The entry condition
   writes "`(r - I(t))ᵀw - λwᵀΣw - Θ|w|^(3/2)`" (penalty on the *target weight* w),
   but the exit section states "The model itself determines the need to trade via the
   term `|w - w₀|^(3/2)`" (penalty on *turnover*). ref0 and ref2 implemented the
   formula literally (Θ|w|^{3/2}); ref1 read |w| as shorthand for |w−w₀| per the
   dynamic-rebalancing sentence. Both readings quote spec text; neither can be called
   a violation. This changes whether holding a large position is continuously
   penalized, i.e., the steady-state target weight and every rebalance.
   → `unpinned-entry-trigger` (and it is the trade-gating term, so also exit-relevant).

3. **I(t) has no closed form.** The spec says only "`I(t)` — vector of impact costs,
   where `t = |w - w₀|` — this is the trading volume" and, separately, "costs
   proportional to the size of trading volume raised to the power of 3/2". ref0/ref1
   set I(t)=Θ·t^{3/2}; ref2 set I(t)=Θ·√t so that the *total* cost I(t)·t recovers the
   3/2-power law — the standard square-root-impact reading of "the empirical fact that
   market impact grows faster than trading volume" the spec itself cites. The spec
   never writes I(t)'s formula, so neither reading contradicts explicit text.
   → `unpinned-entry-trigger`.

4. **Estimators for r and Σ are unpinned.** "These values can be calculated based on
   historical returns or a factor model" and "Calculate the covariance matrix based on
   historical asset return data over the same period" pin no estimator. ref0 used
   population variance (`statistics.pvariance`), ref1 backtrader
   `StandardDeviation`², ref2 sample variance (`statistics.variance`, N−1
   denominator). With grid-searched w* fed by these numbers every bar, estimator
   differences alone perturb fill sequences. The lookback itself is only an example:
   "(for example, T=1 year)". → `unpinned-indicator-params`.

5. **Trade trigger threshold.** ref1 skips the order when |w*−w₀| ≤ 1e-9; ref0/ref2
   submit `order_target_percent` every bar. The spec's only guidance is the
   cost-benefit prose ("If the cost of reaching the new optimal portfolio ... exceeds
   the potential benefit, the strategy will not initiate trading"), which pins no
   mechanism. → `unpinned-entry-trigger` / `unpinned-exit`.

## Structural spec gaps (same choice made by all refs, so not divergence drivers, but spec-level)

- **Multi-asset spec on a single-feed binding.** The task requires a "vector of
  expected asset returns", a "covariance matrix", "Constraints on sector exposure",
  and "Liquidity filters" over multiple assets; the bench binds it to one AAPL 1d
  feed. All three refs independently collapsed w, r, Σ to scalars — itself an
  unpinned reduction the spec never sanctions. → `multi-asset-required`.
- **External data.** The factor model ("Σ = XᵀFX + D, where X is the matrix of factor
  loadings, F is the factor covariance matrix") and liquidity filtering require factor
  and liquidity data absent from an OHLCV feed. The factor route is optional ("you can
  use a factor model") but the liquidity filter is stated as a rule.
  → `external-data-required`.
- **Constraints offered only as examples.** "Examples of constraints:" including
  "`l_b = u_b = w₀` (full investment constraint)" — which, read literally, freezes
  w at w₀ and forbids all trading. All three refs dropped it for a [0,1] box; a
  fourth faithful implementation could equally have kept it and produced an empty
  tape. → `unpinned-sizing`.
- **Rebalance frequency is an example.** "at each step (for example, daily or
  weekly)" — all refs chose daily, but weekly is an equally faithful reading with a
  completely different tape. → `unpinned-exit`.
- **Truncated task text.** The prompt ends mid-sentence: "assets with insufficient
  liquidity, since for" — the final filter rules are simply missing. → `other`.

## Repair-candidate analysis (strict)

- **ref0:** implements the objective exactly as written, including Θ|w|^{3/2} on the
  target weight and I(t)=Θt^{3/2}. No spec sentence contradicted.
- **ref1:** its Θ|w−w₀|^{3/2} reading is directly supported by the quoted
  dynamic-rebalancing sentence; the 1e-9 threshold implements "the strategy will not
  initiate trading" prose. No unambiguous contradiction.
- **ref2:** I(t)=Θ√t is the closest call, but the spec never states I(t)'s functional
  form, and ref2's reading reconciles the (r−I(t))ᵀw dimensional structure with the
  cited empirical 3/2 law. "The spec probably meant I(t)=Θt^{3/2}" is not a quotable
  contradiction. Θ=0.1 is unpinned by construction.

No ref violates explicit spec text → `repair_candidates = []`. Repairs would be
pointless anyway: even with a single agreed I(t)/objective form, λ, Θ, the variance
estimator, and the rebalance frequency remain free, so faithful implementations
cannot converge to a unique tape.

## Decision

Divergence (3 successful refs, 3 distinct primary-key tapes) traces entirely to
unpinned spec choices, several of which the spec itself flags as examples or free
parameters, plus an internal contradiction in the objective and a truncated final
section. **INDETERMINATE** with classes `multi-asset-required`,
`external-data-required`, `unpinned-indicator-params`, `unpinned-entry-trigger`,
`unpinned-exit`, `unpinned-sizing`, `other`. Consistent with the static screen's
prediction. Confidence: high.
